# v0.1.3 prerelease plan

Status: frozen candidate contract as of 2026-07-31.

## Release posture

`v0.1.3` is the next single-suite prerelease of `github.com/the-sarge/cpace`. It is an auditable draft-21 snapshot, not a production-ready release. External review issues #29-#31 and independent cryptographic review issue #32 remain open for the future production-readiness path but do not block this explicitly non-production-ready prerelease.

ADR-0010 consideration, any proposal or review gate, monorepo implementation, cpace-x25519 disposition, and all cross-suite evidence work are outside this release and this branch. Any later accepted breaking repository migration would target `v0.2.0`.

## Frozen candidate contract

The exact clean candidate source commit is `1f19e278112fa037890848ed6c086addeffdca4e`. It was selected from a clean worktree after PR #227 reached `main` as merge commit `6be725fe617b2ad47fd260f39382d000c438e292` and issue #231 pinned every repository Go module to Go 1.26.5 while retaining the Go 1.26 language version.

This commit is the immutable package-code, dependency, toolchain, workflow, and evidence-sensitive tooling input for the v0.1.3 evidence lanes in issues #233-#237. Later commits may add evidence artifacts and release documentation without silently moving this source baseline.

The admitted scope excludes Rapid, optional cleanup, new dependencies, new public API or observable behavior, protocol or Message framing changes, package-profile changes, fuzz-harness changes, ADR-0010 consideration or acceptance, monorepo implementation, cpace-x25519 disposition, and cross-suite work or evidence. No ADR-0010 or companion monorepo-plan artifact is included in this branch.

Any post-freeze change to package code, dependencies, the Go toolchain, workflows or evidence-sensitive tooling, protocol or Message framing behavior, fuzz harnesses, package-profile claims, or other security-relevant state invalidates this source baseline. Select and record a new exact clean candidate commit, then restart every affected evidence lane before making a release claim.

## Candidate scope

- Include the single-suite changes present at the frozen candidate source commit, including the breaking pre-v1 `Config` → role-local `Input` migration, removal of exported `Suite`, `Initiator.Close` and `Responder.Close`, the nil-safe `(*Session)(nil).Close()` contract, peer-share error sentinels, zero-value state rejection, internal zeroization/terminal-state hardening, and release-pipeline improvements.
- Pin the local and CI toolchain to Go 1.26.5, the 2026-07-07 security release with fixes in `crypto/tls` and `os` plus compiler, runtime, `go` command, `net`, `os`, and `syscall` bug fixes, while leaving the supported Go language version at 1.26. Treat the toolchain update as an evidence-refresh trigger.
- Include dependency-only PR #227, merged as `6be725fe617b2ad47fd260f39382d000c438e292`, before freezing the candidate. Its intended Action updates remain pinned to full commit SHAs, and the repaired release-policy fixtures preserve SHA-pinning and supported-action checks.
- Correct the external-review handoff so it no longer claims that the evidence pinned to `f7efa6a963a954952b1ecad3f46530f13799fe89` covers current package code after PR #219.
- Do not add Rapid or any other dependency. Do not add new public API, observable behavior, protocol, parser/framing, package-profile, or optional cleanup work unless a release finding forces a policy reopen and the maintainer explicitly approves it.
- Keep optional issues, testing experiments, repository-hardening improvements, ClusterFuzzLite work, and ADR-0010 work out of the candidate. Any later promotion is a scope reopen that selects a new candidate and restarts affected evidence lanes.

## Breaking pre-v1 migration notes

The release notes must lead with the fact that `v0.1.3` contains breaking changes despite the patch version:

- Replace `Config` with `Input`. Initiators set `SelfID=initiator` and `PeerID=responder`; responders reverse that orientation. `AssociatedData` becomes role-local `LocalAssociatedData`.
- Remove `Suite` and `SuiteCPaceRistretto255SHA512`; callers should remove those references because the package remains single-suite with opaque framing.
- Treat `(*Session)(nil).Close()` as a successful no-op rather than an `ErrInvalidInput` case.
- Document the additive lifecycle and error surface: `Initiator.Close`, `Responder.Close`, `ErrPeerShareEncoding`, and `ErrPeerShareIdentity`.
- State that the wire format and the `CPACE-RISTR255-SHA512` draft-21 suite remain unchanged.
